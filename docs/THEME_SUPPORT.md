# Native KDE theme support (planned)

Aim to respect supported Qt/Kirigami/Plasma color, dark/light, typography and icon preferences with accessible controls and a documented fallback. User-supplied `references/kde-system-apps/` shows observed Breeze and KDE application UI, not an API contract. Theme import must not execute third-party scripts. Test on real Fedora KDE, not screenshots alone. Arbitrary Plasma Global Theme portability remains unverified.
