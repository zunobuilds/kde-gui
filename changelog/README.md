# Changelog

Daily summaries of meaningful repository changes, newest first.

**Timezone:** Asia/Singapore — Singapore Standard Time (SGT), UTC+08:00. Each day runs from local midnight to the next local midnight. Any recorded times use the 24-hour clock and the `+08:00` offset.

## Format and maintenance

- Use one `DD-MM-YY.md` file per active day, headed `# DD/MM/YY`.
- Update the existing day's file as changes occur; omit duplicate bullets and inactive days.
- Group concise bullets under **Added**, **Changed**, **Fixed** or **Removed**, using only relevant categories.
- Keep entries focused on public repository changes, without internal operations, credentials or private paths.

Historical changes are reconstructed from verified Git history using committer timestamps converted to Asia/Singapore. The available history begins on 27 October 2026; no earlier entries are inferred from dates mentioned in planning documents.
