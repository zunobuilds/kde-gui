# 27/10/26

Timezone: Asia/Singapore (SGT, UTC+08:00).

## Added

- Planning documentation for the Rust, Qt 6, QML/Kirigami and CXX-Qt library, including separate Rust and QML interfaces.
- MIT OR Apache-2.0 licence texts, with licensing rationale and dependency guidance.
- Daily changelog files, a newest-first index and a link from the project README.
- Shared repository contribution and maintenance guidelines in `AGENTS.md`.
- Experimental Rust counter with saturation semantics and an optional CXX-Qt state bridge.
- Independently importable QML counter component, a native Qt plugin wrapper and local installation support.
- Separate Rust and QML consumers, packaged-consumer checks and automated state, binding, notification, keyboard and instance-isolation tests.
- Build instructions and a reviewed dependency-version and licence inventory.
- Debugger-seeded integer-limit integration checks covering bridge notifications, label updates, automatic button disabling and accessibility announcement events.
- Optional AT-SPI inspection helper and exact native desktop verification commands with a manual acceptance checklist.

## Changed

- Clarified that quota safeguards belong to the global Codex launcher and retired launcher verification is no longer a development gate.
- Updated library documentation to distinguish verified native rendering, controlled light/dark appearances, resizing, synthetic input and AT-SPI delivery from remaining physical-scaling and audible screen-reader checks.
- Updated development guidance to use the standard workspace sandbox and removed the retired launcher prerequisite.
- Updated repository operation rules while retaining repository-only writes and the prohibition on sudo and sandbox bypass.
- Shortened the README and organized the roadmap into Markdown milestone checklists.
- Reworked technical, decision, appearance and accessibility documentation into focused sections.
- Proposed a task-list application as a broader library showcase; the example selection remains open.

- Extended counter tests for keyboard focus state, pressed/released states, cancelled clicks, disabled input and layout with larger fonts.
- Documented Wayland startup and test-runner exposure limitations, verified native consumer rendering and outstanding acceptance checks.
